BuyerBias - AI Based Spending Manager with Extra Insights

BuyerBias is a tool meant to be used as a third person perspective, for major spending decisions. It takes the user's main finances as input, and stores it in sessions.
This means there is no permanent storage of the user's sensitive data. 
BuyerBias allows the user to download a final report of the spending decision with all important statistics computed using Python, and the API calls to Gemini form the debate of For v/s Against.
